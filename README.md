# WonPice (원피스) — 쇼핑몰 독립 & 올바른 선택 자가진단

> **"최저가 출혈 경쟁에 휘둘리지 않고, 내 가게의 가치를 지키는 올바른 선택"**
> 
> *Won*: 타인을 짓밟는 경쟁이 아닌, 내 브랜드의 주체성과 지속 가능성을 지켜내는 승리  
> *Pice*: 경영의 올바른 기준 한 조각 (Right Principle)

---

## 📌 프로젝트 소개
**WonPice**는 스마트스토어, 쿠팡 등 오픈마켓에서 판매 중인 소상공인·농가·패션 대표님들이 플랫폼의 과도한 수수료와 최저가 알고리즘 종속에서 벗어나, 소중한 단골을 온전한 내 자산으로 만드는 **'쇼핑몰 독립 적합도 자가진단 및 경영 가이드'** 마이크로 서비스입니다.

동시에, 소상공인 전문 자사몰 구축·운영 서비스인 **[가게지기(Gagejigi)](https://shop-site-950864605215.asia-northeast3.run.app)**로 진성 고객(Lead)을 자연스럽게 연결하는 **아웃바운드 브릿지** 역할을 수행합니다.

---

## 🚀 주요 기능
1. **30초 초직관적 자가진단 (Diagnostic Engine)**:
   - 업종/품목 성격 (산지직송 농산물, 수제 가공식품, 디자이너 패션 등)
   - 단골 고객 반응 및 재구매 신호 분석
   - 현재 겪고 있는 핵심 병목 (고객 데이터 종속, 가격 비교, 수수료 등)
   - 월 매출 규모 슬라이더를 통한 독립 준비도 점수 (0~100점) 산출
2. **현실적인 수수료 절감 & 손익 시뮬레이션**:
   - 연간 플랫폼 추정 수수료 산출
   - 단골 25% 자사몰 전환 시 연간 절감액 및 자사몰 유지비 차감 후 순이익 시각화
3. **스마트스토어 + 자사몰 상생 병행 가이드**:
   - 플랫폼 폐쇄가 아닌, 신규 유입(스마트스토어)과 단골 정착(자사몰)의 역할 분담 전략 제시
4. **가게지기(Gagejigi) 아웃바운드 연계**:
   - 식품·농가 '제철곳간' 데모몰 & 패션 '온결' 데모몰 직접 체험 연결
   - 선착순 10곳 농가·식품 구축비 50% 프로모션 안내 및 맞춤 상담 링크 제공

## 🛠️ 기술 스택
- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Icons**: Lucide React
- **Deployment**: Vercel / Cloud Run 최적화 (정적 SSG 프리렌더링)
