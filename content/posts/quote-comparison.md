## 총액보다 제품 구성을 먼저 맞추세요

커튼 견적을 비교하려면 **같은 창, 같은 원단·주름·겹수, 같은 설치 범위**인지 먼저 확인하세요. 같은 “암막커튼”이라는 이름도 원단 품명과 제작 방식은 다를 수 있습니다. 조건이 다른 부분을 표시한 뒤 같은 조건으로 바꾼 내역을 요청하면 총액 차이를 이해하기 쉽습니다.

## 커튼 견적서에서 확인할 항목

직접 받은 견적을 아래 항목으로 정리하세요. 공간별 치수와 측정 기준이 같은지 확인하고 원단 이름, 주름 방식, 부자재를 내역 그대로 적습니다.

| 항목      | 적어 둘 내용             | 상담 시 질문                        |
| --------- | ------------------------ | ----------------------------------- |
| 원단      | 품명·색상·기능·관리법    | 샘플과 실제 제작 원단이 같나요?     |
| 제작      | 크기·겹수·주름·개폐 방향 | 실측 뒤 어떤 항목이 바뀌나요?       |
| 부자재    | 레일·봉·브래킷·끈        | 기존 부자재 재사용 시 내역은요?     |
| 실측·설치 | 방문·시공·철거 범위      | 추가 비용이 발생하는 조건은요?      |
| 사후관리  | 접수 방법·기간·비용 조건 | 원단·시공 문제를 어떻게 접수하나요? |

## 복사해 채우는 견적 비교 양식

아래는 **메모장이나 문서에 복사해서 채우는 빈 양식**입니다. 이 페이지에서 입력하거나 자동 계산하는 표가 아닙니다. 업체별 가격을 수집해 보여 주는 자료도 아닙니다. 견적서 한 건마다 표를 복사하고 방이나 창이 다르면 행을 나누세요.

상단에 적을 내용: 상담 업체 `________` / 견적일 `________` / 공간·창 `________` / 측정 기준 `________` / 원단·주름·겹수 `________`.

| 견적 항목           | 세부 내용·수량 | 비용 상태: 한 가지 선택       | 금액·변경 조건 메모 |
| ------------------- | -------------- | ----------------------------- | ------------------- |
| 원단·제작           | ________       | □ 포함 / □ 별도 / □ 확인 필요 | ________            |
| 레일·봉·브래킷      | ________       | □ 포함 / □ 별도 / □ 확인 필요 | ________            |
| 방문 실측           | ________       | □ 포함 / □ 별도 / □ 확인 필요 | ________            |
| 설치 작업           | ________       | □ 포함 / □ 별도 / □ 확인 필요 | ________            |
| 기존 제품 철거·폐기 | ________       | □ 포함 / □ 별도 / □ 확인 필요 | ________            |
| 추가 작업           | ________       | □ 포함 / □ 별도 / □ 확인 필요 | ________            |

“포함”은 받은 총액에 들어 있다는 뜻이고, “별도”는 따로 청구되는 항목입니다. 설명이 없다면 0원이나 포함으로 추정하지 말고 “확인 필요”로 남기세요. 해당 작업을 하지 않는 경우에는 세부 내용에 “작업 없음”이라고 적습니다. 마지막에 최종 총액, 세금 포함 여부, 실측 후 변경 조건을 다시 확인하세요.

> 상태 기록 예시: 레일 교체 / 1개 / 별도 / 금액 확인 필요. 이 예시는 표를 채우는 방법을 보여 주며 실제 견적 사례나 권장 수량이 아닙니다.

두 내역이 다르면 먼저 공간과 제작 치수를 맞추고, 다음으로 원단·주름·겹수를 비교하세요. 그 뒤 레일·실측·설치·철거 포함 범위를 확인합니다. 설명이 없는 칸은 비워 두고 아래 상담 메모의 질문으로 다시 요청하세요. 여러 업체가 실제로 제시한 내역이 있을 때 작성하는 비교 방법입니다.

## 포함 범위와 추가 비용을 확인하세요

현장 실측 비용, 방문 가능 지역, 설치비, 기존 제품 철거와 폐기 처리 여부를 각각 확인하세요. 높은 창이나 특수 설치면에 추가 작업이 필요한지도 물어봅니다. 실측 후 크기나 원단 구성이 바뀌면 금액이 어떻게 달라지는지 확인하고 최종 내역을 요청하세요.

> 상담 질문 예시: “실측과 설치가 포함된 총액인가요? 레일 교체와 기존 커튼 철거가 별도라면 각각의 금액과 추가 작업 조건을 적어 주세요.”

### 무료 견적 신청이면 방문 실측과 설치도 무료인가요?

**신청 비용과 방문·실측·설치 비용은 각각 확인해야 합니다.** 이 사이트의 ‘무료 견적 신청’ 버튼은 외부 신청 페이지로 연결됩니다. 버튼 문구만으로 출장이나 설치 작업까지 무료라고 판단하지 마세요. 신청 절차와 정보 전달 방식은 [서비스 안내](/about)에서 확인할 수 있습니다.

방문 일정을 잡기 전에는 “방문 실측에 비용이 있나요?”, “계약하지 않아도 청구되는 비용이 있나요?”, “안내한 지역이나 작업 범위를 벗어나면 어떤 비용이 추가되나요?”를 물어보세요. 계약 여부에 따라 달라지는 조건이 있다면 금액과 적용 시점을 함께 적어 달라고 요청합니다.

검증되지 않은 평균 가격이나 할인율로 판단하기보다 실제 받을 제품과 서비스가 명확한지 보세요.

## 일정과 사후 조건을 함께 결정하세요

제작·설치 가능일, 결제 방식, 변경·취소 조건, 사후관리 접수 방법과 비용 조건을 확인합니다. 구두로만 들은 내용은 최종 견적 내역과 함께 다시 확인해 두는 것이 좋습니다.

AS는 접수 연락처, 원단과 부자재·시공 각각의 처리 범위, 출장이나 교체 비용 조건을 나눠 물어보세요. 기간만 있고 적용 조건이 없다면 상담에서 보완해 적습니다. 견적에 차이가 남으면 [맞춤커튼 가격 결정 요소](/guides/companies/curtain-cost-factors)를 기준으로 어떤 항목이 달라졌는지 확인하세요.

이 사이트는 커튼전문점 상담을 준비하는 정보와 도우미를 제공합니다. 자체 시공이나 여러 업체의 실시간 가격 비교를 제공하지 않으며 특정 업체의 가격 우위를 보증하지 않습니다.
