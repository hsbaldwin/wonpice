## 총액보다 제품 구성을 먼저 맞추세요

커튼업체 견적을 검토할 때 같은 “암막커튼”이라는 이름만으로 같은 제품이라고 판단하지 마세요. 원단 품명·겹수·주름 방식·개폐 방향이 다르면 제작 내용도 달라집니다. 공간별로 내역을 나누면 무엇이 다른지 확인하기 쉽습니다.

## 상담에 사용할 견적 확인 양식

직접 받은 견적을 아래 항목으로 정리하세요. “미포함”과 “아직 확인하지 않음”을 구분하는 것이 핵심입니다. 이 표는 사용자가 작성하는 비교 양식이며 이 사이트가 업체별 가격을 수집해 제공하는 자료는 아닙니다.

| 항목      | 적어 둘 내용             | 상담 시 질문                        |
| --------- | ------------------------ | ----------------------------------- |
| 원단      | 품명·색상·기능·관리법    | 샘플과 실제 제작 원단이 같나요?     |
| 제작      | 크기·겹수·주름·개폐 방향 | 실측 뒤 어떤 항목이 바뀌나요?       |
| 부자재    | 레일·봉·브래킷·끈        | 기존 부자재 재사용 시 내역은요?     |
| 실측·설치 | 방문·시공·철거 범위      | 추가 비용이 발생하는 조건은요?      |
| 사후관리  | 접수 방법·기간·비용 조건 | 원단·시공 문제를 어떻게 접수하나요? |

## 포함 범위와 추가 비용을 확인하세요

현장 실측 비용, 방문 가능 지역, 설치비, 기존 제품 철거와 폐기 처리 여부를 각각 확인하세요. 높은 창이나 특수 설치면에 추가 작업이 필요한지도 물어봅니다. 실측 후 크기나 원단 구성이 바뀌면 금액이 어떻게 달라지는지 확인하고 최종 내역을 요청하세요.

> 기록 예시: 원단과 제작은 포함 / 레일 교체는 별도 확인 필요 / 기존 커튼 철거는 미확인 / 희망 설치일 전달 완료.

검증되지 않은 평균 가격이나 할인율로 판단하기보다 실제 받을 제품과 서비스가 명확한지 보세요.

## 일정과 사후 조건을 함께 결정하세요

제작·설치 가능일, 결제 방식, 변경·취소 조건, 사후관리 접수 방법과 비용 조건을 확인합니다. 구두로만 들은 내용은 최종 견적 내역과 함께 다시 확인해 두는 것이 좋습니다.

이 사이트는 커튼전문점 상담을 준비하는 정보와 도우미를 제공합니다. 자체 시공이나 여러 업체의 실시간 가격 비교를 제공하지 않으며 특정 업체의 가격 우위를 보증하지 않습니다.
