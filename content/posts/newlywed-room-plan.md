## 색감은 연결하고 기능은 나누세요

신혼집커튼 구성은 모든 방을 같은 제품으로 맞추기보다 용도부터 나누는 편이 좋습니다. 거실은 자연광과 출입, 침실은 수면 시간, 작은방은 서재나 드레스룸처럼 실제 사용 방식을 기준으로 봅니다.

비슷한 색 계열이나 질감으로 분위기를 이어갈 수 있지만, 같은 흰색도 원단과 조명에 따라 다르게 보입니다. 마감재와 함께 샘플을 확인하세요.

## 방별 요구사항 작성 예시

아래는 작성 방법을 보여주는 가상의 예시입니다. 치수와 구성은 실제 공간에 맞춰 바꿔 적으세요.

| 공간   | 창틀 치수 예시        | 필요한 기능            | 우선순위     |
| ------ | --------------------- | ---------------------- | ------------ |
| 거실   | 가로 300 × 세로 200cm | 낮 채광·저녁 시선 보호 | 입주 전      |
| 침실   | 가로 180 × 세로 150cm | 아침 빛 줄이기         | 입주 전      |
| 작은방 | 미측정                | 화면 반사 줄이기       | 가구 배치 후 |

치수 기준과 대략 여부를 적고, 미측정한 창은 비워 둡니다. 불확실한 값을 정확한 제작 크기처럼 전달하지 마세요.

## 도우미와 별도 메모를 함께 쓰세요

현재 도우미는 **한 견적의 치수와 기능을 이 브라우저에 저장**합니다. 여러 방이나 창을 추가해서 한 문서로 모으는 기능은 제공하지 않습니다. 여러 방은 위 표를 참고해 별도 메모로 정리하고, 먼저 상담할 창을 도우미에 입력하세요.

브라우저 데이터를 지우면 저장 내용이 사라질 수 있고 다른 기기로 자동 동기화되지 않습니다. 신청 페이지에 치수·요구사항이 자동 전달되지 않으니 상담 때 직접 공유하세요.

## 구성 변경이 쉬운 견적을 요청하세요

전체 금액만 받기보다 방별 원단·제작·부자재·설치 내역을 구분해 달라고 요청하세요. 예산이나 일정에 맞춰 일부 방부터 진행할 때 어떤 항목이 바뀌는지 확인하기 쉽습니다. 창문 개수와 제품 종류도 실제 신청 양식에 맞게 준비하세요.
