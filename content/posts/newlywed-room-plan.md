## 색감은 연결하고 기능은 나누세요

신혼집의 거실·침실 커튼은 **집 전체의 색감과 각 방에서 필요한 기능을 따로 정한 뒤 조합**하면 선택하기 쉽습니다. 거실은 자연광과 출입, 침실은 수면 시간, 작은방은 서재나 드레스룸처럼 실제 사용 방식을 기준으로 봅니다.

비슷한 색 계열이나 질감으로 분위기를 이어갈 수 있지만, 같은 흰색도 원단과 조명에 따라 다르게 보입니다. 마감재와 함께 샘플을 확인하세요.

## 거실과 안방의 색상 조합을 좁히세요

먼저 벽지·바닥·소파·침구 사진을 한곳에 모으고 두 사람이 함께 좋아하는 색 계열을 정하세요. 그다음 방별로 낮 채광과 야간 시선 차단, 빛을 줄일 시간을 적습니다. 거실에서 고른 원단을 안방에도 그대로 쓸지는 기능을 확인한 뒤 결정하세요.

예를 들어 거실은 밝은 속커튼과 차분한 겉커튼, 안방은 같은 색 계열의 암막 원단을 검토할 수 있습니다. 이는 조합을 생각하는 예시이며 모든 신혼집에 맞는 제품 추천은 아닙니다. 두 원단을 한 번에 놓고 낮 자연광과 저녁 조명 아래에서 비교하면 상담할 후보를 좁히기 쉽습니다.

색상만 결정하고 이중커튼을 모든 방에 넣기보다 각 방에서 두 층을 따로 사용할 필요가 있는지 확인하세요. 공간이 좁거나 창 아래 가구가 있다면 개폐와 관리가 편한 구성도 함께 비교합니다.

## 방별 요구사항 작성 예시

아래는 작성 방법을 보여주는 가상의 예시입니다. 치수와 구성은 실제 공간에 맞춰 바꿔 적으세요.

| 공간   | 창틀 치수 예시        | 필요한 기능            | 우선순위     |
| ------ | --------------------- | ---------------------- | ------------ |
| 거실   | 가로 300 × 세로 200cm | 낮 채광·저녁 시선 보호 | 입주 전      |
| 침실   | 가로 180 × 세로 150cm | 아침 빛 줄이기         | 입주 전      |
| 작은방 | 미측정                | 화면 반사 줄이기       | 가구 배치 후 |

치수 기준과 대략 여부를 적고, 미측정한 창은 비워 둡니다. 불확실한 값을 정확한 제작 크기처럼 전달하지 마세요.

예산이나 일정 때문에 일부 방부터 진행한다면 첫날부터 필요한 기능을 기준으로 우선순위를 적으세요. 생활에 꼭 필요한 시선·빛 조절과 색상 취향, 아직 확정되지 않은 가구 배치를 구분하면 상담에서 바꿀 수 있는 범위가 명확해집니다. 나중에 추가할 방이 있다면 원단 재고와 재방문 작업 조건도 함께 물어보세요.

## 도우미와 별도 메모를 함께 쓰세요

현재 도우미는 **한 견적의 치수와 기능을 이 브라우저에 저장**합니다. 여러 방이나 창을 추가해서 한 문서로 모으는 기능은 제공하지 않습니다. 여러 방은 위 표를 참고해 별도 메모로 정리하고, 먼저 상담할 창을 도우미에 입력하세요.

브라우저 데이터를 지우면 저장 내용이 사라질 수 있고 다른 기기로 자동 동기화되지 않습니다. 신청 페이지에 치수·요구사항이 자동 전달되지 않으니 상담 때 직접 공유하세요.

## 구성 변경이 쉬운 견적을 요청하세요

전체 금액만 받기보다 방별 원단·제작·부자재·설치 내역을 구분해 달라고 요청하세요. 예산이나 일정에 맞춰 일부 방부터 진행할 때 어떤 항목이 바뀌는지 확인하기 쉽습니다. 창문 개수와 제품 종류도 실제 신청 양식에 맞게 준비하세요.
