# 홈 첫 섹션과 도우미 수정 기준

최신 요청(2026-09-07)은 **저장 견적 선택 드롭다운과 저장 버튼을 제거하고, 현재 견적 하나를 자동 저장하는 것**입니다. 얇은 헤더, 탭 없는 도우미, 간결한 두 번째 섹션과 공간별 이미지를 유지합니다.

## 현재 구성

홈은 두 개의 스냅 섹션입니다.

1. 첫 섹션 `scene-helper`: 배경 영상 위에 도우미 시작 가이드와 입력 화면을 배치합니다. 기존 별도 소개 섹션과 도우미로 내려가는 버튼은 제거했습니다.
2. 마지막 섹션 `scene-spaces`: 공간별 가이드와 푸터를 한 화면에 표시합니다.

첫 섹션은 일반 배치 헤더를 제외한 높이(`100svh - --header-height`)를 사용합니다. 헤더에는 좌측 햄버거와 우측 견적 문의만 표시하며 높이는 데스크톱60px·모바일56px입니다. 클릭 영역은44px을 유지합니다. 모바일과 데스크톱 모두 네이티브 스크롤 스냅을 적용하며 텍스트 입력 중·모션 감소 설정의 접근성 예외를 유지합니다.

헤더와 푸터의 브랜드명 표시는 제거했습니다. 푸터에는 네비게이션 없이 저작권과 제휴 안내만 표시합니다.

전역 글꼴은 **나눔스퀘어 네오**입니다. 네이버 공식 가변 WOFF2를 프로젝트에 포함하고 루트 레이아웃의 `next/font/local`로 불러옵니다. 헤더·본문·입력창·버튼·포털 드롭다운·가이드·푸터가 같은 글꼴을 사용합니다.

## 두 번째 섹션의 여백

가이드 영역을 남는 높이만큼 늘리지 않고 푸터 위 가용 영역의 세로 중앙에 배치합니다. 데스크톱의 가이드·푸터 내용은 최대 1120px 폭으로 정렬하고 가이드 사진은 최대 252px 높이로 제한합니다. 모바일은 작은 정사각형 이미지와 제목·설명·화살표가 나란히 놓이는 목록이며 외곽 카드 배경·테두리를 사용하지 않습니다. 모바일 좌우 여백은 24px입니다. 짧은 가로 화면에서는 낮은 사진의 3열 배치를 사용합니다.

3개 가이드의 제목·설명·링크와 푸터의 저작권·제휴 고지는 유지합니다. 섹션 전체는 `100svh`이며 별도 내부 스크롤이나 콘텐츠 숨김으로 맞추지 않습니다.

공간별 사진은 제목과 일치해야 합니다. 거실은 넓은 창과 쉬폰·소파, 침실은 침대와 베이지색 암막, 신혼집은 두 의자가 있는 원형 식탁과 크림·세이지색 이중커튼의 서로 다른 이미지를 사용합니다. 한 사진을 위치만 바꿔 반복하지 않습니다. 최종 파일과 생성 프롬프트는 [제작 기록](guide-image-prompts.md)에 보관합니다.

## 첫 화면과 도우미 흐름

- 탭은 제거합니다. 시작 후 상단 오른쪽에 **새로 작성**을 테두리 버튼으로 표시합니다.
- 안내: **맞춤커튼, 문의 전 간단한 준비**.
- 제목: **우리 집 견적을 미리 정리해보세요.**
- 설명: **입력하면 자동 저장돼요. 문의할 때 참고하세요.**
- 주요 버튼: **시작하기**. 자동 저장된 현재 견적의 마지막 작성 단계로 이어집니다. 기록이 없으면 빈 치수 입력을 엽니다.

안내·제목·설명·버튼을 가로와 세로 중앙에 정렬합니다. 시작 화면은 단일 중앙 영역을 사용하고, 입력 화면은 동일한 높이의 상단 도구 행·하단 상태 행으로 중심을 유지합니다. 외곽 카드·테두리·그림자는 사용하지 않습니다.

시작 후 같은 섹션에서 다음 세 화면으로 이어집니다.

1. 가로·세로 치수와 측정 기준·측정 상태.
2. 자연광·암막·시선 보호·빛 조절의 복수 선택.
3. 입력한 치수·필요 기능 요약과 **견적 문의** 버튼 하나. 저장·PDF·도움말·입력 수정 버튼은 표시하지 않습니다.

창문 개수와 분위기는 새 입력 흐름에서 받지 않습니다. 기존 여러 공간·창 문서는 보존하며, 해당 문서에서는 선택한 창을 전환해 입력·요약합니다. 기능은 같은 공간의 창에 함께 적용됩니다. 견적 선택 목록과 초안·저장본 구분은 제거합니다. 입력·기능·단계 변경은 현재 견적 하나에 자동 저장하며, 결과에는 문의 버튼만 남깁니다. 새로 작성은 확인 후 현재 견적을 새 ID의 빈 치수 입력으로 교체합니다. 문의 시 입력 내용은 자동 전달되지 않는다는 안내를 유지합니다.

단일 저장 키는 `masters:quote-current:v1`입니다. 처음 전환할 때만 이전 초안과 저장 목록에서 실제 입력이 있는 최신 문서를 가져옵니다. 과거 데이터 키는 변경하지 않으며 이후에는 새 단일 저장 키만 읽고 갱신합니다. 새로 작성한 빈 기록이 존재해도 과거 저장본을 다시 가져오지 않습니다. 브라우저 저장 접근 오류·용량 부족은 화면에 알리고, 읽지 못한 기록을 기본값으로 덮어쓰지 않습니다. 같은 브라우저의 다른 탭 변경을 반영하며 오래된 탭의 종료 저장을 방지합니다.

`#helper`, `/?view=saved#helper`, 저장 문서 열기 링크를 보존합니다. 현재 화면의 주 제목 하나만 H1입니다. 서버 HTML에서도 시작 안내와 영상 포스터를 제공합니다.

## 영상과 가독성

기존 4K 쉬폰 원본을 중앙 안내에 적합한 근접 구도와 구간으로 새로 편집합니다. 다른 원본으로 교체했다는 의미는 아닙니다. 데스크톱·모바일 각각의 루프와 동일 구도 포스터를 사용합니다. 편집 원본·납품 해상도·라이선스와 디코딩 검증은 [미디어 기록](media-sources.md)에 보관합니다.

시작 화면은 중앙을 밝히는 그라데이션, 입력·저장 화면은 섹션 전체의 밝은 면으로 대비를 조절합니다. 입력 전체를 박스로 감싸거나 원본을 블러 처리하지 않습니다. 수동 재생·정지 버튼과 ‘스타일 예시’ 표시는 추가하지 않습니다.

## 반응형 검수 기준

- 제목·입력·설명·버튼이 한 화면 안에서 겹치지 않아야 합니다.
- 짧은 가로 화면은 치수와 측정 설정을 나란히 배치하고 기능을 4열로 표시합니다.
- 작은 모바일은 여백과 줄 높이를 조절합니다. 가로 화면에서 저장 견적과 창 선택은 나란히 놓습니다.
- 드롭다운은 OS 기본 select 대신 동일한 디자인의 combobox와 포털 목록을 사용합니다. 화면 가장자리를 벗어나지 않게 배치하고 방향키·Home/End·Enter·Escape·Tab 탐색을 제공합니다.
- 내용 숨김·내부 스크롤·전체 transform 축소로 맞추지 않습니다.
- 자동 저장·기존 문서·문의 동작을 유지합니다. PDF는 현재 도우미에서 제공하지 않습니다.
- 영상 재생·포스터, 단일 H1, 기존 링크, 마지막 섹션과 푸터를 함께 확인합니다.

실제 확인한 화면 크기와 검사 결과는 [검증 기록](verification.md)에 남깁니다. 브라우저 화면 크기 검수는 실제 모바일 기기의 키보드·글자 확대 검증과 구분합니다.
