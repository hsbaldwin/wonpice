# 현재 사이트 구성 정의

기준: 2026-09-09 개선 구현본. 운영 배포 전입니다.

**커튼 견적 도우미는 사용자가 창 치수와 필요한 기능을 정리하고, 커튼 선택 가이드를 읽은 뒤 견적 상담을 신청하도록 돕는 사이트입니다.**

서비스는 상담 준비 도구, 정보 콘텐츠, 외부 견적 신청 연결로 구성됩니다. 직접 시공하거나 여러 업체의 실시간 가격을 비교하지 않습니다. 가격·제작 규격·제품 성능·설치 조건은 상담에서 확인합니다.

| 영역                  | 역할                                            | 다음 행동                        |
| --------------------- | ----------------------------------------------- | -------------------------------- |
| 홈 `/`                | 현재 견적 하나의 치수·기능 정리와 브라우저 저장 | 저장한 내용 확인 → 견적 문의     |
| 커튼 가이드 `/guides` | 준비할 내용·공간별로 필요한 정보 찾기           | 카테고리 또는 개별 글 읽기       |
| 카테고리 6개          | 검색 의도별 판단 기준·체크리스트                | 관련 글·무료 견적 신청·치수 정리 |
| 글 10개               | 구체적인 질문에 답하는 요약·목차·비교표·예시    | 상담 준비 → 신청 또는 다음 글    |
| 서비스 안내 `/about`  | 제공 범위·저장·신청 절차·수수료 안내            | 서비스 이해 후 도우미 또는 신청  |
| 관리자 `/admin`       | 방문·문의와 날짜별 신청·승인 실적 확인          | 기간 비교·실적 입력·CSV          |

공개 콘텐츠는 총 19페이지이며 관리자·API·신청 이동 경로·저장 북마크는 콘텐츠 수에 포함하지 않습니다. 현재 비공개 설정에서는 공개 대상 페이지도 검색엔진에 noindex로 제공합니다.

## 탐색 구조

```text
홈 (도우미 + 공간별 가이드)
커튼 가이드
├─ 준비할 내용으로 찾기
│  ├─ 설치·시공 (2개 글)
│  ├─ 업체·견적 (2개 글)
│  └─ 스타일·소재 (2개 글)
└─ 공간으로 찾기
   ├─ 거실커튼 (1개 글)
   ├─ 침실커튼 (1개 글)
   └─ 신혼집커튼 (2개 글)
서비스 안내
```

메뉴는 홈·커튼 가이드·서비스 안내를 선택하는 수단입니다. Breadcrumb는 현재 읽는 콘텐츠의 상위 경로를 보여 줍니다. 글에서는 **홈 > 커튼 가이드 > 카테고리 > 글 제목**, 카테고리는 홈 > 커튼 가이드 > 카테고리, 서비스 안내는 홈 > 서비스 안내입니다. 화면과 JSON-LD가 같은 경로를 사용합니다.

도우미는 홈 안의 `#helper`입니다. 독립 `/helper` 페이지는 없습니다. `/?room=...#helper`는 도우미 시작 조건이며 별도의 색인 페이지가 아닙니다. 기존 `/saved`는 `/?view=saved#helper`로 연결합니다.

## 저장과 신청

현재 견적 하나를 브라우저에 저장하며 다른 기기와 동기화하지 않습니다. 여러 방 자료 추가·PDF 다운로드는 현재 홈에 없습니다. 여러 창의 치수는 가이드 예시를 참고해 별도 메모로 준비합니다.

무료 견적 신청은 `/go/quote`와 공식 추적 URL을 경유합니다. 입력 치수·요구사항은 신청 양식에 자동 전달되지 않습니다. 신청 페이지는 이름·연락처·제품 종류·창문 개수·설치 주소를 받으며, 이 사이트의 통계에는 해당 개인정보를 수집하지 않습니다.

서비스 안내와 가이드 하단 문구: “이 링크를 통한 신청으로 운영자에게 수수료가 발생할 수 있습니다.”

## 성과 해석

방문수는 익명 세션 기준, 문의 클릭률은 방문 세션 중 문의 클릭 세션의 비율입니다. 현재 공식 링크는 다른 채널에서도 사용되므로 날짜별 신청·승인 수치는 전체 채널 신청 실적입니다. 이 수치를 사이트 방문수로 나누지 않습니다. 사이트 전용 링크가 확보된 이후의 실적만 적용일부터 구분합니다.

설정과 상세 정의는 [운영 통계 설정](analytics-setup.md)을 참고하세요.
