# SEO 검색 노출 후보 키워드

작성일: 2026-09-10 KST. 대상: 커튼 견적 도우미 프로젝트.

진행 상태: 아래 표는 최초 분석 시점의 진단과 제안이다. 이후 요청에 따라 로컬 코드에 키워드·콘텐츠·이미지를 반영했다. 실제 반영 범위, 검증 결과와 배포 상태는 [SEO 및 콘텐츠 구현 기록](seo-implementation-2026-09-10.md)을 참조한다.

최신 후속 작업: 홈 대표어를 `커튼 견적`으로 명확히 하고 기존 글의 관련 답변을 보강했다. 현재 19페이지의 검색 의도와 이번 변경·검증 상태는 [커튼 견적 검색 의도 보강 패치](seo-search-intent-patch-2026-09-10.md)를 참조한다.

현재 콘텐츠에 가장 잘 맞는 방향은 **맞춤커튼 견적 준비 + 실측·선택·설치 조건을 묻는 구체적인 검색어**다. 우선순위는 콘텐츠 적합성과 상담 연결성을 판단한 것이며, 검색량·키워드 난이도·예상 순위의 측정값이 아니다.

분석 범위는 홈, 가이드 허브, 카테고리 6개, 글 10개, 서비스 안내의 공개 대상 19페이지다. 소스와 콘텐츠를 읽고 관련 웹 검색 결과의 표현과 페이지 유형을 참고했다. Google Search Console 계정 데이터, Google Ads·네이버 검색광고의 검색량, 네이버 통합검색의 영역별 노출은 확인하지 않았다. 운영 사이트의 현재 색인 상태도 이번 분석에서 재검증하지 않았다.

## 3. 넓은 대표 키워드

커튼, 맞춤커튼, 커튼 견적, 맞춤커튼 견적, 커튼 가격, 맞춤커튼 가격, 커튼 설치, 커튼 시공, 커튼 전문점, 커튼 업체, 인테리어 커튼, 거실 커튼, 침실 커튼, 신혼집 커튼, 쉬폰커튼, 암막커튼, 이중커튼.

이들은 사이트 주제를 설명하는 대표어다. 다만 현재 사이트의 구체적인 답변과 맞는 세부 검색어를 우선 검증하는 편이 적절하다. 특히 업체·견적 검색 결과에는 실제 견적 비교 서비스인 [미소의 커튼 설치 페이지](https://miso.kr/curtains)가 나타난다. 이런 페이지와 비교할 때, 이 사이트의 견적 준비 도구와 비교 체크리스트를 명확히 설명하는 방향을 권한다. 이는 관찰한 결과 유형에서 도출한 판단이며 경쟁 강도 측정이 아니다.

암막 관련 검색에서는 [창너머꿈의 암막·빛샘 안내](https://www.dreamwindow.co.kr/stories/blackout-curtain.html)처럼 문제를 직접 설명하는 콘텐츠도 확인했다. 이를 질문형 콘텐츠 후보 선정에 참고했으며, 해당 문서의 제품 성능 주장이나 검색량을 검증한 것은 아니다.

## 5. 현재 서비스와 맞지 않는 타깃

- `커튼 가격 계산기`, `커튼 견적 자동 계산`: 도우미는 치수와 기능을 정리하며 금액을 계산하지 않는다.
- `커튼 최저가 비교`, `실시간 커튼 업체 비교`: 여러 업체 가격을 실제로 수집·비교하는 기능이 없다. `커튼 견적 비교 방법`은 정보 콘텐츠로 사용할 수 있다.
- `서울 커튼 시공`, `부산 커튼 전문점`, `근처 커튼 매장`: 현재 사이트는 지역별 업체 정보나 자체 시공 실적을 제공하지 않는다. 기존 기획에도 지역별 페이지 추가가 포함되지 않는다.
- `커튼 시공 후기`, `커튼 업체 순위`: 검증된 직접 경험·후기·평가 자료가 없다.
- `무료 커튼 설치`, `무료 방문 실측`: 외부 견적 신청의 무료 안내와 시공·출장·실측 비용 면제는 별개다.
- `무타공 커튼 설치법`, `전동커튼 설치`, `커튼 세탁법`: 현재 글에서 충분히 답하지 못한다. 실제 안내 내용을 확보한 뒤 별도 검토한다.

## 6. 검색어에 맞춘 제목 예시

아래는 최초 분석에서 제안한 사이트명 접미사 이전의 제목 예시다. 이후 로컬 구현에 반영하면서 일부 문구를 다듬었다. 최종 제목은 각 페이지 소스와 글의 frontmatter를 기준으로 한다.

- 홈: `커튼 견적 상담 준비: 치수·원단·설치 조건 정리` (후속 패치의 현재 제목)
- 실측 글: `커튼 사이즈 재는 법: 창문 치수와 설치 범위 구분하기`
- 견적 비교 글: `커튼 견적 비교 방법: 원단·레일·설치비 확인사항`
- 가격 글: `맞춤커튼 가격이 달라지는 이유: 견적을 바꾸는 6가지 조건`
- 원단 글: `쉬폰·암막·이중커튼 비교: 밤 비침과 빛 차단 확인하기`
- 침실 글: `암막커튼 빛샘, 원단과 설치 틈을 함께 확인하세요`
- 입주 글: `입주 전 커튼 설치 시기: 실측부터 설치까지 준비 순서`

핵심어는 제목과 본문의 실제 답변에 반영한다. 동일 단어를 반복하거나 키워드 목록만 추가하는 작업을 목표로 삼지 않는다. Google은 meta keywords를 사용하지 않으며, 명확한 제목과 독자에게 도움이 되는 내용을 권장한다. 모든 검색 표현을 정확히 반복할 필요도 없다고 설명한다. [Google SEO 기본 가이드](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)

`거실커튼/거실 커튼`, `맞춤커튼/맞춤 커튼`, `커튼/커텐` 같은 표현은 향후 검색어 보고서에서 함께 살펴볼 수 있다. 본문은 읽기 쉬운 표준 표현으로 작성하고, 표기 변형만을 위해 별도 페이지를 만들지 않는다.

## 7. 실제 노출 데이터로 검증하기

초기에는 대표 후보 10개와 관련어를 기준으로 노출이 발생한 검색어·페이지 조합을 확인한다. 운영 검토 주기는 28일로 제안하되, 이는 노출이나 순위 상승에 걸리는 기간의 예측이 아니다. 데이터가 적으면 평가 기간을 늘린다.

Search Console에서는 검색어와 페이지별 노출수·클릭수·CTR·평균 게재순위를 볼 수 있다. 실제 관측된 검색어를 기준으로 제목과 답변의 일치 여부를 점검한다. [Google Search Console 실적 보고서](https://support.google.com/webmasters/answer/7576553?hl=en-EN)

- 노출이 생기는 검색어: 해당 페이지가 질문에 충분히 답하는지 확인한다.
- 노출은 있으나 클릭이 적은 검색어: 게재순위와 검색 결과 유형을 함께 보고 제목·설명을 검토한다.
- 검색 방문은 있으나 문의 클릭이 적은 페이지: 콘텐츠와 다음 행동의 연결을 확인한다.
- 예상하지 못했던 관련 검색어: 기존 글에 답을 추가할지 새로운 주제가 필요한지 판단한다.

사이트 관리자 통계의 방문·문의 클릭과 Search Console의 검색어 데이터는 별도로 해석한다. 현재 공유 제휴 링크의 전체 신청 실적으로 검색어별 신청 전환율을 계산하지 않는다.
