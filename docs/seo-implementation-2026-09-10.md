## 콘텐츠와 이미지의 표현 기준

- 도우미는 치수와 필요한 기능을 정리한다. 금액 계산, 실시간 업체 비교, 직접 시공 기능을 새로 제공하는 것으로 표현하지 않았다.
- 사진에는 AI 스타일 또는 구성 예시 설명을 넣었다. 실제 시공 사례나 측정한 암막 성능의 근거로 사용하지 않는다.
- 실측·빛샘·비침 도해에는 텍스트 설명을 함께 제공했다. 그림의 간격과 밝기는 제품 성능 수치가 아니다.
- 각 대표 이미지에 의미 있는 alt, 실제 원본 크기와 반응형 sizes를 제공한다. 읽기 페이지의 대표 이미지 한 개만 preload하고 카드는 기본 지연 로딩한다.
- 검증된 금액 자료 없이 평균 가격·평형별 비용·최저가를 만들어 넣지 않았다. 가격 글은 비용을 바꾸는 조건을 설명한다.
- 키워드 우선순위는 콘텐츠 적합성과 상담 연결성을 판단한 결과다. 검색량·경쟁 강도·노출 순위 예측값은 확보하지 않았다.

## 브라우저 및 배포 상태

이미지 통합 이전의 SEO·본문·도해 버전은 로컬 HTTP로 공개 페이지 19개를 확인했고, 320·390·768·1440px의 76개 화면 조합에서 가로 넘침·누락 이미지·H1·도해 잘림을 점검했다. 결과는 `output/seo-keywords/browser-qa.json`에 있다. 이 결과를 최종 이미지 통합 버전의 브라우저 통과로 해석해서는 안 된다.

이후 로컬 서버 재시작 요청은 자동 승인 검토 도구의 사용량 제한 때문에 실행되지 않았다. 따라서 **최종 이미지 통합 버전의 브라우저·HTTP 재검증은 남아 있다.** 위 최종 검증은 빌드 및 정적 산출물 기준이다.

운영 배포에 필요한 비공개 Vercel 프로젝트 화면 접근은 자동 승인 검토에서 거절됐다. 사유는 현재 요청만으로 비공개 배포·조직 정보 접근에 대한 명확한 승인을 확인할 수 없다는 것이었다. 다른 경로로 우회해 접근하거나 배포하지 않았다. 사용자의 해당 프로젝트 접근·배포 승인 및 도구 실행 가능 상태가 확보되면 다음 순서로 마무리한다.

1. 최종 로컬 서버로 19페이지 HTTP 검증과 4개 반응형 폭의 브라우저 검증을 다시 실행한다.
2. 홈의 두 화면 구성·푸터, 이미지 로딩·크롭·키보드 포커스·비교표 스크롤을 확인한다.
3. 승인된 Vercel 프로젝트에 배포한 후 해당 변경과 연결된 배포가 Ready인지 확인한다.
4. 실제 도메인의 canonical·robots·사이트맵·대표 이미지와 공개 페이지를 확인한다.
5. Search Console에 접근할 권한과 세션이 확보되면 실제 검색어·페이지 데이터를 확인한다. 28일 검토는 분석 주기 제안이며 자동 반복 작업을 생성한 것은 아니다.

이번 작업에서는 운영 사이트의 현재 노출 수치, Search Console 실적, 예상 검색 순위를 확인하지 않았다.
