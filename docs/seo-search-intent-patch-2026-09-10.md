# 커튼 견적 검색 의도 보강 패치

작성일: 2026-09-10 KST. 대상: 커튼 견적 도우미의 공개 페이지 19개.

이번 패치는 홈을 **커튼 견적 상담을 준비하는 대표 페이지**로 명확히 하고, 관련 질문을 다루는 기존 글과 연결하는 작업이다. 사용자가 요청한 관련 키워드의 상위 노출을 목표로 구현했지만, 검색 순위나 모든 키워드의 1위 노출을 보장하는 작업은 아니다. 검색량·경쟁 강도·예상 순위를 산출하지 않았으며 Google Search Console과 네이버 서치어드바이저의 실제 검색어·색인·노출 데이터를 이번 작업에서 조회하지 않았다.

사이트명은 **커튼 견적 도우미**, 공개 경로는 기존 19개를 유지한다. 외부 견적 신청 경로와 제휴 링크, 브라우저 저장 방식도 유지한다. 비슷한 검색 표현마다 새 페이지를 만들거나 근거 없는 가격·후기·시공 지역을 추가하지 않았다.

**검증 및 전달 상태:** 이번 패치의 자동 테스트는 131개 중 129개 통과·2개 건너뜀·실패 0개이며 타입·전체 포맷·공개 설정 프로덕션 빌드를 통과했다. 19페이지 HTTP SEO 검사와 4개 너비의 76개 화면 조합도 통과했다. 아래에는 이번 실행의 로그와 직접 브라우저 확인 범위를 기록한다. 이 문서는 로컬 검증 시점의 기록이며 원격 커밋과 운영 반영 결과는 작업 최종 답변에 기록한다.

## 구현 근거와 유지한 조건

- `app/page.tsx`, `app/home.css`, `lib/site.ts`: 홈 제목·첫 답변·설명과 4개 핵심 가이드의 배치.
- `content/posts/curtain-cost-factors.md`, `quote-comparison.md`, `measurement-basics.md`, `living-room-light.md`: 관련 질문의 본문 답변 보강. 기존 H2와 목차 ID, 시각자료·CTA 표식 수를 유지했다.
- `app/sitemap.ts`, `lib/guide-images.ts`: 공개 19개 경로에 실제 등록된 사진을 연결한다. 검색 비공개 설정에서는 빈 사이트맵을 유지한다.
- `lib/seo.ts`: 페이지별 제목·설명·canonical 및 검색 공개 상태를 유지하며 큰 이미지 미리보기 허용을 추가한다.
- `components/guide-ui.tsx`, `app/guides/page.tsx`, `app/guides/[category]/[slug]/page.tsx`: 허브의 글 목록과 작성자 표시·구조화 데이터 일치.

공개 경로와 검색 제외 경로를 바꾸지 않았다. 관리자·API·신청 이동 경로를 검색용 페이지로 확장하지 않는다. 외부 신청 경로 `/go/quote`와 기존 제휴 연결을 유지한다. 치수·요구사항을 외부 양식에 자동 전달하지 않으며 사이트 내부 개인정보 접수 폼도 추가하지 않았다.

원본 글 4개의 `dateModified`는 수정 당일인 `2026-09-10`으로 이미 표시되어 있어 유지했다. 나머지 글의 날짜를 이번 작업을 이유로 일괄 변경하지 않았다.

## 운영 후 평가

검색 공개 허용, 검색엔진의 실제 색인, 특정 검색어 노출과 순위를 구분한다. 색인 신청이나 구조화 데이터 추가가 상위 노출을 확정하지 않으므로 실제 보고서의 검색어·페이지 조합을 기준으로 후속 개선을 결정한다.

배포 시점을 기준으로 동일한 길이의 28일 구간을 비교하되, 이 기간은 순위 상승 예상 기간이 아니다. 표본이 작거나 색인이 충분하지 않으면 관찰 기간을 늘린다. 자동 반복 작업은 생성하지 않는다.

- 검색 성과: Google Search Console과 네이버 서치어드바이저의 실제 검색어·랜딩 페이지·노출·클릭을 확인한다. 제공되는 지표와 검색 결과 영역의 차이를 구분한다.
- 사이트 행동: 홈·글별 문의 이동과 도우미 진행·복사 이벤트를 별도로 확인한다. 치수나 복사한 내용은 통계로 수집하지 않는다.
- 외부 신청: 공유 제휴 링크의 실제 신청 건수를 사이트의 페이지별·검색어별 실적으로 배분하거나 사이트 전환율로 계산하지 않는다.
