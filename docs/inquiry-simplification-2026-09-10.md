# 문의 흐름 간소화와 제휴 연결 검증

작성일: 2026-09-10 KST.

사용자 요청에 따라 상담 전달 문구 생성·복사·수동 복사 입력란을 제거했다. 홈과 글에서 무료 견적 신청으로 바로 이동하며, 치수 도우미는 선택적으로 이용한다. 기존 19개 공개 URL, 검색 주제, 이미지와 시각자료, 브라우저 저장 형식은 유지한다.

## 변경 내용

- 홈 도우미와 아티클의 상담 문구 복사 컴포넌트·스타일·글별 템플릿을 제거했다.
- 홈 FAQ, 신청 절차, 서비스 안내와 CTA 설명을 직접 신청 흐름에 맞췄다.
- 관리자 화면에서 복사 기능의 성과 행을 제거했다. 과거 기록 및 이미 열린 이전 클라이언트를 위해 기존 이벤트 허용 목록과 집계 호환성은 유지한다. 새 화면에서는 복사 이벤트를 발생시키지 않는다.
- 공통 제휴 URL을 `http://tnr.kr/ma/link.php?lncd=S00281518OC06031025V`로 변경하고 사이트 설정도 같은 정의를 사용한다.
- 동일한 제휴 코드의 tnr.kr·dbdbdeep.com 주소 차이를 사이트 전용 코드로 오인하지 않도록 검증했다. 공유 코드의 신청 실적을 사이트 전환율로 계산하지 않는다.
- `/go/quote`는 기존 302·no-store·noindex 응답을 유지한다. 계측 실패가 이동을 차단하지 않으며 HEAD 검사에서는 클릭 이벤트를 생성하지 않는다.

## 연결 검증 범위

실제 브라우저에서 홈의 견적 신청 버튼을 한 번 눌러 요청한 제휴 주소를 경유한 뒤 공식 신청 양식으로 이동하는 것을 확인했다. 최종 양식의 `ms=S00281518O`와 `ca=C06031025V`도 일치했다. 제휴 관리자에서 방문 전후 클릭 증가를 확인했다.

사용자가 직접 신청한 뒤 제휴 관리자 상세 내역에서 해당 캠페인의 신규 접수를 확인했다. 다만 제공자의 처리 메모는 테스트, 처리 상태는 승인거부로 표시되었다. **신청 귀속 확인과 수수료 승인 확인은 서로 다르며, 이번 접수로 지급 실적이 검증되지는 않았다.** 제공자가 테스트로 분류한 구체적인 판정 기준은 화면에 표시되지 않았다. 신청자 정보와 계정별 실적 수치는 저장소 문서에 포함하지 않는다.
