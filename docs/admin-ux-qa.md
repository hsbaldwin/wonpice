# 관리자 통계 사용성 검증

검증일: 2026-09-10. 운영 데이터와 분리된 로컬 SQLite 테스트 자료를 사용했습니다.

## 구현 범위

- 기본 화면은 오늘의 요약입니다. 요약·유입/페이지·도우미/신청 버튼·실적 입력의 네 화면을 `view`로 선택하며 기간을 유지합니다.
- 오늘은 어제 같은 시각까지 비교하고, 여러 날은 직전 같은 길이의 기간으로 비교합니다. 비교 결과에 기간·가능 여부·불가 사유를 포함합니다.
- 핵심 지표, 비교, 상세 자료, 실적 조회를 분리했습니다. 일부 쿼리 실패가 정상 핵심 지표를 없애지 않습니다.
- 페이지 검색·카테고리·정렬, 10개씩 더 보기, 모바일 카드, 그래프/수치 표, 한국어 CSV를 제공합니다.
- 실적 0건과 미입력을 구분하고 기존 값 불러오기·미입력 날짜 이동·수정 초점 이동·저장 후 갱신을 제공합니다.
- 이벤트, 개인정보 수집, DB 스키마, 관리자 인증, 공개 사이트 흐름은 변경하지 않았습니다.

## 자동 검증

- `npm run typecheck`, `npm run build` 통과.
- `npm test`: 실행된 105개 통과. 별도 HTTP 환경이 필요한 2개 항목은 아래에서 실행합니다.
- 관리자 HTTP fixture: 인증 없는 접근 차단, 쿠키·로그아웃·Origin 검증, 네 화면 SSR, 기존/한글 CSV, 실적 0건 수정·미입력 구분 통과.
- SQL은 SQLite와 PostgreSQL(PGlite) 모두 기존 집계·중복·KST 날짜 경계·유입 귀속·실적 저장 회귀를 통과했습니다.
- 추가 검증: KST 자정, 같은 시각 절단, 7/28/90일·직접 기간, 이전 값/분모 0, 보관 기록 부족, 상세 쿼리 실패, DB 전체 실패, 화면별 필요한 쿼리 선택, CSV 수식 이스케이프.
- 로컬 프로덕션 빌드의 공개 19페이지 HTTP·고유 메타데이터·본문·앵커·구조화 데이터·신청 링크·robots/사이트맵 확인. 로컬은 기존 비공개 설정을 사용했습니다.

## 브라우저 검증

- 네 화면 × 320·390·768·1440px: 문서 가로 넘침 없음. 주요 메뉴·버튼·입력·펼침 영역 높이 44px 이상.
- 모바일 카드 및 PC 표, 요약 4개 지표 배치, 그래프 지표 전환과 날짜별 수치 펼침 확인.
- Tab 초점의 3px 외곽선과 Enter 기간 이동 확인.
- 페이지 19개 중 기본 10개와 더 보기, 제목 검색, 카테고리로 결과 없음 표시 확인.
- 직접 지정한 과거 기간과 화면 이동 시 날짜 유지, 상세 측정 전 기간, 기록 없음과 비교 기록 부족 안내 확인.
- 오늘의 기존 실적 신청 0/승인 5가 입력 폼에 미리 채워짐을 확인. 미입력 날짜 이동 시 빈 입력값과 초점, 저장 성공 시 합계·목록·미입력 일수 갱신, 목록 수정 시 해당 날짜·값·초점 이동 확인.
- 테스트 서버를 종료한 뒤 저장을 시도하여 한국어 연결 실패 안내와 입력값 유지 확인.
- 공개 도우미의 기존 저장 내용 복원·시작 화면 복귀 확인. `/go/quote`가 기존 공식 추적 링크로 302 이동함을 확인했으며 외부 상담 양식은 제출하지 않았습니다.
- 관리자 핵심 수치·표·메뉴는 서버 HTML 검사로 JavaScript 실행 없이 조회 가능함을 확인했습니다. 필터·더 보기·실적 입력은 기존대로 JavaScript를 사용합니다.

## 배포 확인

기존 `greybrander-prog/wonpice`의 `main` → Vercel 경로를 사용합니다. 운영 확인에서는 관리자 접근 보호·캐시 금지·noindex와 공개 19페이지의 응답 및 검색 공개 상태를 확인합니다. 이 변경에는 DB 설정이나 마이그레이션이 필요하지 않습니다. 테스트용 로컬 서버는 검증 후 종료합니다.
